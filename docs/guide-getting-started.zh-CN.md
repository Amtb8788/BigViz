# 新手上手：三句话做出一块大屏

不用懂 YAML、不用懂抠图，跟 AI 说 2–3 句话就能拿到一块能跑的 1920×1080 大屏。

## 准备（只做一次，约 3 分钟）

1. 安装插件（Claude Code 里输入）：
   ```
   /plugin marketplace add Amtb8788/BigViz
   /plugin install bigviz@bigviz
   ```
2. 配置出图服务（可选，没有也能出页面）：
   ```bash
   export BIGVIZ_API_KEY=...        # 任意 OpenAI 兼容 Images API，切勿提交到仓库
   export BIGVIZ_MODEL=gpt-image-1
   ```

## 三轮对话

**第 1 句：说你想要什么**

```
/bigviz 给智慧工地做一个安全指挥中心大屏，深蓝科技风，中文
```

AI 会自己写好需求（6 个面板、4 个指标、示例数据），回你一张汇总表，只问一句"可以开始出图吗"。

**第 2 句：确认或改几处**

```
可以，把"人员排行"换成"设备在线率"，标题改成"XX 项目安全驾驶舱"
```

AI 出 4 张设计稿拼成一张对比图，标出每张的错字数，并推荐一张。

**第 3 句：选一张**

```
用 2 号
```

AI 修字、抠出 3D 素材、写好 Vue 3 页面并通过类型检查。你运行 `npm run dev` 打开页面，
AI 截图验收，告诉你还有哪些可以优化。

## 说法小抄

| 想要 | 这样说 |
|---|---|
| 换风格 | "换成克制的金融风" / "换成玻璃拟态" |
| 多比几版 | "用精修模式，先做风格比稿" |
| 3D 数字孪生 | "中间做成 3D 城市，告警点能点击飞过去" |
| 已有设计稿 | "我有设计稿，在 designs/xxx.png，照着做" |
| 接真实数据 | "把面板数据改成调 /api/screen 接口" |
| 只改一块 | "左下角面板太空了，精修一下" |

## 三种风格

| 预设 | 适合 |
|---|---|
| `deep-tech-blue`（默认） | 指挥中心、智慧工地、智慧城市 |
| `editorial-dark` | 管理层、金融看板 |
| `aurora-glass` | 发布会、营销展示墙 |

## 常见问题

- **没有 API Key？** 照样能出页面，AI 先用模板自带素材，之后再换图。
- **设计稿里的字是错的？** 没关系，页面上的文字全部由代码渲染，一定准确。
